MarkdownReader 隐私政策

最后更新日期：2026年5月4日

MarkdownReader（以下简称"本应用"）尊重并保护用户隐私。本隐私政策说明本应用如何处理您的信息。

1. 数据收集

本应用不收集任何用户数据。我们不会收集、存储或传输您的个人信息、设备信息、使用行为或任何其他数据。

2. 数据存储

您通过本应用导入或创建的所有文档均存储在您的设备本地沙盒目录中。这些数据不会上传至任何服务器，也不会与任何第三方共享。

3. 网络访问

本应用仅在以下情况下访问网络：

  • 您主动输入 URL 导入网络文章时，应用会下载该 URL 的内容
  • 渲染 Mermaid 图表和 LaTeX 数学公式时，需要从 CDN 加载开源 JavaScript 库

以上网络请求不包含任何用户身份信息。

4. 第三方服务

本应用不集成任何第三方分析、广告或数据收集服务。

5. 分享扩展

分享扩展功能仅在您的设备本地运行，通过系统剪贴板或 App Group 在应用间传递数据，不经过任何外部服务器。

6. 儿童隐私

本应用不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

7. 隐私政策变更

如果我们更新本隐私政策，将在此页面上发布最新版本，并更新"最后更新日期"。
