MarkdownReader Privacy Policy

Last updated: May 4, 2026

MarkdownReader ("this App") respects and protects user privacy. This privacy policy explains how this App handles your information.

1. Data Collection

This App does not collect any user data. We do not collect, store, or transmit your personal information, device information, usage behavior, or any other data.

2. Data Storage

All documents you import or create through this App are stored locally in your device's sandbox directory. This data is never uploaded to any server or shared with any third party.

3. Network Access

This App accesses the network only in the following cases:

  • When you actively enter a URL to import a web article, the App downloads the content from that URL
  • When rendering Mermaid diagrams and LaTeX math formulas, open-source JavaScript libraries are loaded from a CDN

These network requests do not contain any user identity information.

4. Third-Party Services

This App does not integrate any third-party analytics, advertising, or data collection services.

5. Share Extension

The Share Extension feature runs entirely on your device. Data is transferred between apps via the system clipboard or App Group, without passing through any external server.

6. Children's Privacy

This App is not directed at children under 13 and does not knowingly collect personal information from children.

7. Changes to This Policy

If we update this privacy policy, we will post the latest version on this page and update the "Last updated" date.
